🔄 Synchronisation

Colle ici l'adresse du déploiement Apps Script « Intranet HSE ». Tant que ces champs sont vides, la page fonctionne uniquement sur cet appareil.

🔒 Accès à la consultation

Le mot de passe de consultation se pose côté serveur, dans la propriété INTRANET_LECTURE du script — jamais dans cette page ni sur GitHub. Chacun le tape une fois sur son appareil, et c'est fini.

À faire sur une tablette de chantier ou un PC partagé qu'on laisse à quelqu'un d'autre : le mot de passe sera redemandé et les données gardées ici seront effacées.

Partager l'intranet

Le lien « collègue » donne la lecture (portail + indicateurs). Le lien « éditeur » permet en plus de mettre à jour les chiffres et les tuiles.

Le lien éditeur contient le mot de passe : envoie-le par SMS ou Teams, pas sur un canal public.
