# Intranet HSE — CDES (V3.7)

Une seule page pour tout le monde : accueil (indicateurs + outils), suivi des nouveaux
arrivants, documents, et — pour le service HSE seulement — la zone HSE (briques) et le Reporting.

- `index.html` · `css/intranet.css` · `js/intranet.js` — l'intranet
- `js/retex.js` — 📘 RETEX de fin de chantier (liste par agence, fiche, formulaire avec photos, import des tableaux Excel convertis)
- `js/qhp.js` — 🎓 espace QHP (vidéo, flash, quiz, émargement) et son édition
- `js/terrain.js` — 📬 suivi des remontées terrain, 🚨 pré-déclaration d'accident, 🔒 zone HSE en briques (à faire, faits marquants, année précédente)
- `js/bulletin.js` — l'accueil « bulletin HSE » (faits marquants, AT, reporting N-1/N, Vigiminutes, QHP, flashs) et le mode affichage `?affichage=IDF`
- `hse.html` · `css/hse.css` · `js/hse.js` — le Reporting HSE, application à part ouverte depuis la zone HSE (code éditeur requis)
- `js/configuration.js` — lit `config.js`
- `config.js` — **le seul fichier à adapter** : adresse `/exec` du script « Intranet HSE CDES »
- `img/` — logo, bonhomme, logo et certificat MASE

Aucun mot de passe, aucun nom, aucune donnée dans ce dépôt.
